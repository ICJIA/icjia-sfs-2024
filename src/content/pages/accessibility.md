The Illinois Criminal Justice Information Authority (ICJIA) is committed to making the Safe From the Start website usable by everyone, including people with disabilities. We treat accessibility as an ongoing responsibility and work to meet or exceed the standards that apply to State of Illinois websites.

## Conformance status

This website **substantially conforms** to the [Web Content Accessibility Guidelines (WCAG) 2.1](https://www.w3.org/TR/WCAG21/) at **Level AA**. "Substantially conforms" means the site meets the WCAG 2.1 Level AA success criteria, with the understanding that some content may occasionally fall short despite our efforts.

Meeting WCAG 2.1 Level AA also addresses the site's obligations under:

- the **Illinois Information Technology Accessibility Act (IITAA) 2.1**, the standard for State of Illinois agency websites, which is based on WCAG 2.1 Level AA; and
- **Title II of the Americans with Disabilities Act (ADA)**, which requires state and local government web content to meet WCAG 2.1 Level AA.

## Measures to support accessibility

Accessibility is built into how this site is designed and developed. Among other measures, the site:

- uses semantic HTML with clearly defined landmark regions (header, navigation, main content, and footer) so assistive technologies can navigate the page structure;
- is fully operable with a keyboard, with a visible focus indicator on every interactive element;
- provides a "skip to main content" link so keyboard and screen-reader users can bypass repeated navigation;
- meets WCAG Level AA color-contrast requirements for text and interface elements;
- respects the operating-system "reduce motion" setting and avoids unnecessary animation;
- uses responsive layouts and relative units so content reflows and remains readable when text is enlarged or the browser is zoomed; and
- delivers page content as static HTML that remains readable if JavaScript is unavailable.

## How this site is tested

We evaluate accessibility ourselves throughout development rather than relying on a single point-in-time review. Testing includes:

- automated checks with **axe-core** and **Lighthouse** during development; and
- ongoing site-wide monitoring with **Siteimprove**.

This is a self-evaluation and is not a third-party certification. Automated tools cannot catch every barrier, which is why feedback from people who use the site is important to us.

## Technical specifications

Accessibility of this site relies on the following technologies: **HTML**, **CSS**, and **JavaScript**. These are used in ways that conform to the standards above. Content pages are delivered as static HTML and remain accessible if JavaScript is turned off or unsupported; JavaScript enhances features such as site search but is not required to read the site's content.

## Feedback and contact

We welcome your feedback on the accessibility of the Safe From the Start website. If you encounter a barrier, or need information from this site in a different format, please contact us:

- **Email:** [cja.info@illinois.gov](mailto:cja.info@illinois.gov)

To help us respond quickly, please include the web address (URL) of the page, a description of the problem, and the browser or assistive technology you were using. We aim to respond as quickly as possible.
